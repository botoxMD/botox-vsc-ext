# Configure Botox Defaults

Set your preferred default author name, organization, document themes, and typesetting parameters.

These defaults are written to `~/.config/botox/config.yaml` and will be automatically applied whenever you create or compile documents.

### Run Configuration Wizard

Click the button below to launch the step-by-step setup wizard:

[Configure Defaults](command:botox.setup)

Or run setup interactively in the terminal:

[Run in Terminal](command:botox.setupTerminal)
