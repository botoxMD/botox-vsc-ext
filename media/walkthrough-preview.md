# Live PDF Preview & Export

Enjoy instantaneous live PDF vector previews with synchronized scrolling and direct PDF compilation.

### Live Preview
Open any Markdown document and press `Ctrl+K V` (or `Cmd+K V` on macOS) to see the live rendering:

[Open Live Preview](command:botox.openPreview)

### Compile to PDF
Compile the active document directly to a standalone PDF:

[Compile to PDF](command:botox.compilePdf)
