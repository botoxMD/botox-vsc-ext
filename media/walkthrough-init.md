# Create Documents and Slide Decks

Botox makes it effortless to scaffold new publication-grade documents and presentations with your configured defaults.

### Initialize a Document
Create a new LaTeX-grade Markdown document with frontmatter, bibliography, and math equations:

[Initialize Document](command:botox.initDocument)

### Initialize Presentation Slides
Create a 16:9 Marp-compatible presentation slide deck:

[Initialize Slide Deck](command:botox.initSlides)
